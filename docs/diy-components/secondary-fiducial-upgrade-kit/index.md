# Secondary Fiducial Upgrade Kit

## Instructions

### Assemble the Bracket

- Gather `secondary-fiducial-bracket`, 2x `m3x10mm-hex-head`, and 2x `m3-wing-nut`.

    ![](img/1.webp)

- Place 2x `m3x10mm-hex-head` into `secondary-fiducial-bracket`

    ![](img/2.webp)

- Attach `m3-wing-nut` onto each `m3x10mm-hex-head`

    ![](img/3.webp)
    ![](img/4.webp)

### Bag the Kit

- Place assembled `secondary-fiducial-bracket` in `3x4-bag`

    ![](img/5.webp)

- Place `punched-holes-kit` in `3x4-bag`

    ![](img/6.webp)

!!! alert "Please Note"
    For instructions on how to assemble `punched-holes-kit`, see [`tool-kit`](/lumen/tool-kit/) page.
