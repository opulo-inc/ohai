## QC

### Visual QC

Visually inspect each PCB before programming.

* Look for bent/missing pins and connectors.
* Ensure all buttons actuate without sticking.
* If any boards fail QC, place them in the red bin near the programming station.

### Programming

* Place the board into the jig by aligning the bottom edges, then gently press the board onto the pins.
    * Be sure that the board does not slide/rotate while making contact with the pins, as this may cause them to bend or make contact with each other.
    * Keep light pressure on the board during programming
* If not already open on the programming laptop, open a terminal, then type `flashphoton` and hit enter to program the board.
    * The up arrow can also be pressed to cycle through previous commands.
* The light on the board will turn red once programming is successful.
    * \*photo of PCB with red light on\*
* If the terminal shows "MIS-MATCHED!" for any of the lines, programming was unsuccessful.
    * Reseat the board in the jig and try again.
    * If programming is still unsuccessful, set the board in the red bin near the programming station.
* Programmed boards get placed in the trays at the programming station.
